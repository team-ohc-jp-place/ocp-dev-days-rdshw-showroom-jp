左から右に、各ステップが保険申込のライフサイクルを処理します。

* `platform-http` — 保険申込を受信する API エンドポイント
* `transform-x12` — EDI データを XML に変換します
* `sql` — バックエンドデータベースにデータを保存します
* `store-pdf-s3` — PDF 保険証券を生成し、S3 にアップロードします

NOTE: 青い *To do: Enable* ブロックが 2 つあります。これらは無効になっており、次の演習で有効にします。最終的には、全体がつながって動作するフローになります。
