== はじめに



顧客からのデータを取り込み、バックエンドデータベースに保存して PDF の保険証券を生成します。Apache Camel が処理を統合し、{rhsi} がセキュアなクラスタ間接続を提供します。

{empty} +

*業務上の要件*

顧客は EDI 形式の保険申込をプラットフォームに送信します。これを取り込み、変換し、バックエンドデータベースに保存して、保管用の PDF 保険証券を生成する必要があります。データベースは別の基盤にあり、OpenShift から直接アクセスできないため、セキュアな接続が必要です。

{empty} +

*構築する技術的なソリューション*

Apache Camel の連携が API エンドポイントを公開し、EDI 形式の保険申込を受信します。フローは EDI を XML に変換し、{rhsi} 経由でバックエンドデータベースに保存して、PDF 保険証券を生成し、S3 オブジェクトストレージ (OpenShift Data Foundation) にアップロードします。

{rhsi} により、データベースをパブリックネットワークに公開せず、OpenShift クラスタとリモートのバックエンドデータベースを安全に接続できます。

{empty} +

*このラボで行うこと:*

. *接続の有効化* — {rhsi} を設定し、バックエンドデータベースへの安全な接続を確立します。
. *フローの完成* — 保険申込の取り込み、変換、保存、保険証券の生成を行う Camel の連携を実装します。
. *テストと検証* — フローをローカルで実行し、結果を確認します。
