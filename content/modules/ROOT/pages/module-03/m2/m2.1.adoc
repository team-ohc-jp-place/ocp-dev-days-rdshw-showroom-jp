== Matrix への参加

{empty} +

[#_join_your_matrix_room]
=== 自分の Matrix ルームに参加する

{blank}

. _Matrix_ の Web クライアントを開きます
+
以下のリンクで _Matrix_ のログインページを新しいタブに開きます。
+
--
- link:{url-element}[Matrix ログインページ,window="_blank"]
--
+
{blank}
+
ログインページが表示されます。
+
{empty} +

. 認証情報でログインします
+
以下のように、認証情報の入力を求められます。
+
image::module-03/m2/matrix-login-credentials.jpg[width=60%]
+
{blank}
+
====
. 以下を入力します。
+
* **Username**
+
[.copypaste.value]
****
{user-username}
****
+
* **Password**
+
[.copypaste.value]
****
[.path]
/credentials/im

[.default]
password

REPLACE
****
+
{empty} +
+
. **_"Sign in"_** をクリックします
====
+
{empty} +
+
本人確認を求められたら、以下のようにパスワードを入力します。
+
image::module-03/m2/matrix-login-confirm.jpg[width=60%]
+
{blank}
+
_"Continue"_ をクリックして確認します。
+
{empty} +
+
_Matrix_ の画面に、自分のルームへの未承諾の招待が表示されます。 +
以下の手順で招待を承諾します。
+
image::module-03/m2/matrix-room-accept-invite.jpg[width=70%]
+
--
. 自分のルームをクリックします
. _"Accept"_ をクリックします
--

{empty} +


[.verification]
****
Matrix のルームに参加できましたか。
****

{empty} +
