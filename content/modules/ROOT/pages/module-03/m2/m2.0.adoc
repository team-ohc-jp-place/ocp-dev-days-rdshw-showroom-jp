[#_the_messaging_scenario]
=== メッセージングのシナリオ

保険申込を送信した顧客は、苦情、補償についての質問、既存の契約の変更などでサポートに連絡することがあります。サポート担当者は、その問い合わせに対応します。

それぞれが *異なる* メッセージングプラットフォームを使う点に注目します。

* *Matrix* — 顧客が問い合わせを送信する場所
* *Rocket.Chat* — サポート担当者が作業し、返信する場所

[TIP]
--
.各プラットフォームについて
[%collapsible]
====
Matrix と Rocket.Chat は、Slack、Telegram、WhatsApp に似たメッセージングプラットフォームです。OpenShift にセルフホストでき、外部アカウントが不要なため、このワークショップで使用します。

*Matrix* は、リアルタイムの分散型通信のためのオープンな標準とプロトコルです。異なるサービスプロバイダ間でも円滑に通信できます。

*Rocket.Chat* は、厳格なデータ保護基準を備えたオープンソースの通信プラットフォームです。Web、デスクトップ、モバイルから、同僚、他社、顧客とリアルタイムに会話できます。
====
--
