[id='dev-environment']
== 開発環境

ここでは、開発環境と、ワークショップを通じてアプリケーションをデプロイするクラスタを紹介します。

[#_overview]
=== 概要

Red Hat OpenShift Dev Spaces は、オープンソースの Eclipse Che を基盤とし、Kubernetes とコンテナにより、開発・IT チームの誰にでも、一貫性がありセキュアで個別設定不要の開発環境を提供します。ノート PC の IDE と同じように、素早く使い慣れた感覚で操作できます。

[.text-center]
image::module-03/intro/devspaces-ide-developer.png[width=70%]

OpenShift Dev Spaces は OpenShift のサブスクリプションに含まれ、Operator Hub から利用できます。開発チームには迅速で信頼性の高い作業基盤を、運用チームには一元的な管理を提供します。

{empty} +

[#_copypaste_commands]
=== コマンドのコピーと貼り付け

ラボ全体でコマンドを使用します。 +
実行するコマンドが手順に表示されたら、以下の図に沿って操作します。

image::module-03/intro/copypaste.png[width=60%]

{blank}

. _Copy to clipboard_ ボタンをクリックします
. ターミナルにコマンドを貼り付けます。
- Linux: kbd:[Ctrl+Shift+v]
- Mac: kbd:[⌘+v]
+
. 以下のコマンドで試します。
+
[.copypaste]
****
echo "this is a multiline \
copy/paste test"
****
+
[NOTE]
====
クリップボードの共有と、操作の確認が求められます。 +
[cols="6,1,8", frame=all, grid=none]
|===
a|
. *Allow* をクリックします
+
image::module-03/intro/devspaces-share-clipboard.png[width=60%]
a|
{empty} +
{empty} +

->

a|
[start=2]
. 確認されたら *[✓] Do not ask me again* にチェックを入れ、*Paste* をクリックします
+
image::module-03/intro/devspaces-paste-confirm.png[width=70%]
|===
====
+
--
WARNING: これらのキー操作が常に機能するとは限りません。動作しない場合は、右クリックや中クリックなど、他のキーやマウスによる貼り付け方法を試してください。
--
