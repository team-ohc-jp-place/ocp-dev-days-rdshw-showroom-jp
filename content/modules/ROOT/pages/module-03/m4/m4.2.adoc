=== 開発サイクルを開始する

ここからは _Camel JBang_ の開発モードで素早く試行します。ルートを変更して保存すると、すぐに自動反映され、再起動せずに動作を確認できます。

まずルートをそのまま実行し、仮の応答を確認します。

{blank}

--

例えば、指定された保険証券の PDF URL を取得するローカルツールは、以下のように定義できます。

image::module-03/m4/kaoto-tool-route.png[width=50%]

--

[#_raise_a_ticket]
=== チケットを作成する

カスタマーサポートは、1 つの操作で完了するとは限りません。契約変更には、変更の確認、返金処理、契約記録の更新、顧客への通知など、複数の部署が関わります。手作業の代わりに、AI エージェントに調整用のチケットを依頼します。

{blank}

[.copypaste.value]
****
Could you please raise a ticket? Include the details explained, and ask the right departments to process the policy amendment accordingly.
****

エージェント型システムは、会話の文脈を基に HelpDesk にチケットを作成し、確認を返します。

{blank}

:fig-time: 6:52 PM
:fig-user-msg: Could you please raise a ticket? Include the details explained, and ask the right departments to refund the customer accordingly.
:fig-bot-msg: A ticket has been created with ID 1025. Would you like to share this ticket with the customer?
include::_figures/rc-interaction.adoc[]

{empty} +
