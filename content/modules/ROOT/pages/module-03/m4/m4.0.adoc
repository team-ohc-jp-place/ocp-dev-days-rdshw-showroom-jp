== ラボ 4 - AI カスタマーサポート

Agentic Apache Camel と Model-as-a-Service (MaaS) により、自然言語のチャットを基に AI エージェントがバックエンドの操作を組み立て、実行します。

{empty} +

*業務上の要件*

保険申込の情報更新、補償の変更、不整合の解決などで顧客から連絡を受けると、従来は担当者が複数のデータベースやファイルシステムを手作業で操作していました。時間がかかり、誤りも起きやすく、担当者と顧客の双方に負担となります。より迅速で円滑な対応方法が必要です。

{empty} +

*技術的なソリューション*

担当者は Rocket.Chat 内で AI ボットに自然言語で依頼します。Agentic Apache Camel と MaaS を活用する AI が、要求を解釈し、呼び出すツールを自律的に判断して、データベースを更新し、S3 上の保険証券を修正して再生成します。対応時間を短縮し、担当者がシステム間を手作業で行き来する作業をなくします。

{empty} +

AI エージェントは推論ループに従います。MaaS 経由で LLM に問い合わせ、実行する操作を判断します。Camel が *MCP* 経由で適切なツールを実行し、データベースの更新や S3 の PDF 保険証券の再生成を行います。結果を LLM に戻し、最終的な回答を Rocket.Chat の担当者へ返します。

[NOTE]
====
*MCP とは* Model Context Protocol (MCP) は、統一されたツール群を通じて、AI エージェントがデータベース、API、ファイルストレージなどの外部システムを操作するためのオープンな標準です。このラボでは Apache Camel が MCP サーバーを実装し、データベースの更新や S3 へのアップロードなどを呼び出し可能なツールとして公開します。AI モデルは自然言語の要求に基づいて、使うツールを判断します。
====

{empty} +

*このラボで行うこと:*

. *環境の準備* — 作業フォルダを準備し、AI エージェントを設定します。
. *エージェントの開発* — 基本ルートからツールを備えた状態へ、段階的に AI エージェントを有効にします。
. *フローの完成* — Rocket.Chat、AI エージェント、データベース、S3 をつなぐ連携を完成させます。
. *フローのテスト* — 顧客と担当者のやり取りを再現し、結果を確認します。

{empty} +
