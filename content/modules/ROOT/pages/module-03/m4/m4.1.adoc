. Kafka と Matrix の連携を有効にします
+
======
Kafka と Matrix の連携をスケールアップします。

[.copypaste]
****
oc scale deployment k2m --replicas=1
****

Pod が起動し、以下の通知フローが有効になります。

[.mermaid]
----

    AI --> KF --> |"k2m\n(pod)"| MX --> CUST

step 7

+
[TIP]
--
.上記のコマンドで、いつでも演習をリセットできます。
[%collapsible]
====
ワークショップには、任意の手順に移動したり、正常な状態にラボを戻したりできるヘルパースクリプトがあります。

* `step N` — ラボを手順 N の開始状態に戻します
* `steps` — 利用できる手順を一覧表示します
* `start` または `restart` — 最初に戻ります (`step 1` と同じです)
* `ff` — *次の* 手順に進みます
* `rw` — *前の* 手順に戻ります
====
