[#_what_youll_learn]
== 学べること

このワークショップでは、以下のことを学びます。

* セルフサービス型の社内開発者ポータルとして Red Hat Developer Hub を探索する
* ソフトウェアカタログを使ってアプリケーション、API、ドキュメントを見つける
* Red Hat OpenShift Dev Spaces で事前設定されたクラウド開発環境を起動する
* AI コーディングアシスタントを使って機能を構築する
* OpenShift Pipelines で自動化された CI/CD パイプラインにコードを送る
* Red Hat OpenShift GitOps (Argo CD) を使って本番環境にデプロイする
* Developer Hub と OpenShift Console からアプリケーションをデバッグし、監視する

[#_who_this_is_for]
== 対象者

このワークショップは、OpenShift が提供する、コードの作成から本番環境へのデプロイまでの統合された開発者エクスペリエンスを理解したい開発者、プラットフォームエンジニア、IT の意思決定者を対象としています。

**経験レベル**: 初級から中級。OpenShift の事前経験は必要ありません。

[#_estimated_time]
== 所要時間

このワークショップの完了には約 **90 分** かかります。

自分のペースで作業できます。

[#_your_role_and_mission]
== あなたの役割とミッション

あなたは **Parasol Insurance** に入社したばかりの開発者です。

Parasol は急速に成長しています。製品ライン、チーム、開発者が増える一方で、プラットフォームチームの対応が追いつきません。新しいチームには、それぞれ専用の CI/CD 設定、Namespace のプロビジョニング、数週間にわたるオンボーディングが必要です。開発者はコードを書くよりも、チケットを起票してアクセス権を待つことに時間を費やしています。ローカル環境も頻繁に壊れたり、構成がずれたりして生産性が下がっています。時折参加する契約社員も、必要な情報やベストプラクティスを見つけるのに時間がかかっています。

心当たりはありませんか。

Parasol のプラットフォームエンジニアリングチームは、この問題の解決に取り組んできました。Red Hat OpenShift 上に統合されたアプリケーションプラットフォームを構築し、開発者ツール、CI/CD、GitOps によるデプロイ、セルフサービス型の社内開発者ポータルを 1 か所で提供します。

**今日があなたの初日です。** プラットフォームへのアクセス権と最初のタスクが与えられました。このワークショップの終了時には、チケットを 1 件も起票せずに本番環境へ機能をリリースできているはずです。

[#_what_you_will_accomplish]
== 達成すること

このワークショップでは、以下を実際に体験します。

* **Red Hat Developer Hub** -- ソフトウェアカタログから API やドキュメントを見つけ、AI アシスタントにプラットフォームについて質問する
* **セルフサービステンプレート** -- ゴールデンパステンプレートで、専用の CI/CD パイプラインを持つ独立した開発環境を作成する
* **Red Hat OpenShift Dev Spaces** -- ローカルに何もインストールせず、AI コーディングアシスタントを備えた設定済みのクラウド IDE でコードを書く
* **OpenShift Pipelines** -- コードをプッシュし、自動化された CI/CD パイプラインが変更をビルド、テスト、スキャンする様子を確認する
* **OpenShift GitOps** -- Argo CD が変更を本番環境へ自動でデプロイする様子を確認する
* **OpenShift Console** -- Web コンソールで詳細なデバッグとアプリケーション監視を行う

[#_the_developer_journey]
== 開発者ジャーニー

このワークショップは、次の一連のストーリーに沿って進みます。

. **プラットフォームとの出会い** -- Developer Hub にログインし、ソフトウェアカタログや全体像を確認する
. **あなたのミッション** -- 割り当てられたタスクを見つけ、開発環境を準備する
. **機能を構築する** -- Dev Spaces を開き、コードを書いてローカルでテストする
. **リリース** -- CI/CD パイプラインにコードを送り、品質ゲートによる検出を体験する
. **AI を呼び出す** -- エージェント型 AI アシスタントでコードを修正し、再度プッシュしてパイプラインを通過する
. **本番環境へ** -- 変更をマージし、リリースを作成して本番環境で機能を確認する

分断されたツールを行き来せず、アイデアから本番環境までを一連の流れで体験できます。

[#_target_audience]
== 想定する参加者

このワークショップは、以下の方に適しています。

* より速く一貫性のある開発ワークフローを求めるソフトウェア開発者
* アプリケーションプラットフォームの機能を評価する IT の意思決定者
* 自分たちが提供する開発者エクスペリエンスを理解したいプラットフォームエンジニア
* OpenShift の開発者ツールを実際に体験したい方

== 前提条件

以下の知識や経験があると役立ちます。

* Web ブラウザとコードエディタの操作経験
