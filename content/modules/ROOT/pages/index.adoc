= OpenShift Dev Day Roadshow
include::partial$_attributes.adoc[]

OpenShift Dev Day Roadshow へようこそ。Red Hat OpenShift で、現代的なアプリケーション開発とシステム連携を体験するハンズオンワークショップです。

[#_available_modules]
== 利用できるモジュール

各モジュールは独立しており、単独で取り組めます。複数のモジュールを通じて、OpenShift の機能を幅広く学ぶこともできます。

[.tile]
****
xref:module-01/00-intro.adoc[Module 1: 開発者エクスペリエンス]

Developer Hub によるセルフサービスの利用開始から、Dev Spaces のクラウド開発、AI コーディング支援、自動 CI/CD、GitOps による本番デプロイまで、OpenShift の開発者ジャーニー全体を体験します。

**所要時間**: 約 90 分
****

[.tile]
****
xref:module-02/00-intro.adoc[Module 2: セキュアなソフトウェアサプライチェーン]

RHDA と ACS の脆弱性スキャン、Sigstore のキーレスコミット署名、Tekton Chains のアテステーション、Conforma のポリシー検証、署名付きリリース承認、Policy Controller のデプロイ制御を使い、SLSA Level 3 に準拠したサプライチェーンでアプリケーションを構築、デプロイします。

**所要時間**: 約 90 分
****

[.tile]
****
xref:module-03/index.adoc[Module 3: AI のためのアプリケーション接続]

Red Hat の連携技術で AI 向けデータフローを構築します。Service Interconnect による EDI の取り込み、Kafka と Matrix / Rocket.Chat によるイベント駆動メッセージング、Agentic Apache Camel の AI サポート、Connectivity Link の LLM ガバナンスを体験します。

**所要時間**: ラボごとに異なります
****

[.tile]
****
xref:module-05/module-05-01-goals.adoc[Module 5: MTA と AI による移行]

Red Hat Developer Lightspeed for Migration Toolkit for Applications (MTA) の静的解析、AI によるリファクタリング、カスタムルール、OpenShift へのデプロイを使い、従来の Java EE / EAP アプリケーションを Quarkus に移行します。

**所要時間**: 約 30 分
****

[#_getting_started]
== 始めましょう

上のモジュールを選択して開始してください。各モジュールに、導入、環境の詳細、学習目標があります。
