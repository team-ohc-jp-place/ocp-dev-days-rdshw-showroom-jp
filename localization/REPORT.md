### 原文由来の確認事項

以下は翻訳に起因する新規不備とは分けて記録しています。

- 両言語とも同じ 22 件のビルド警告があります。リストの固定番号、module-3 の閉じられていない example ブロック、シェル変数 `${URL}` / `${CODE}` / `${CA}` を属性として参照する警告です。後者のコピー欄には、シェル変数が元どおり残ることを確認しています。
- テーマが参照する `_/img/favicon.ico` は英語版にもなく、全公開ページで検出されます。
- module-3 の完了表示用オーバーレイは、初期 HTML では `./` を参照します。実際の操作時はスクリプトでホームの URL に置き換わる構造です。初期 HTML の検査では両言語とも検出されます。
- 実環境用 docserver から認証情報・ルーム ID を取得する処理は、仮ホスト名のローカル環境では両言語とも失敗します。既定値を保持しており、実環境での確認が必要です。
- Mermaid の非同期処理でコンソールの Promise 警告を確認しています。図の定義と読み込む実装は原文と同じで、導入ページでは両言語の SVG 描画を確認しました。実環境でも主要な図を確認します。
- module-5 のデプロイ例は `${NS}` を使用していますが、このページ内にはその代入がありません。Dev Spaces 側で設定されるか、実環境で確認する必要があります。原文のコマンドは変更していません。

英日ホーム画面の保存画像は `screenshots/home-ja.png` と `screenshots/home-en.png` にあります。

細かい検査結果は `verification.json`、`script-verification.json`、`browser-verification.json`、`build-warnings.json` を参照してください。
