= OpenShift Dev Day 日本語版

Red Hat OpenShift のハンズオンワークショップを日本語化した Antora / Showroom コンテンツです。

* Module 1: 開発者エクスペリエンス
* Module 2: セキュアなソフトウェアサプライチェーン
* Module 3: AI のためのアプリケーション接続
* Module 5: MTA と AI による移行

== 日本語化の基準

英語版 https://github.com/rhpds/ocp-dev-days-rdshw-showroom[ocp-dev-days-rdshw-showroom] のローカルチェックアウトを基準にしています。画像ファイル、コード、コマンド、入力例、技術的な参照先は保持しています。

詳しい対象、原文との差分、実施した確認、既知の確認事項は link:localization/REPORT.md[日本語化・確認結果] を参照してください。翻訳元のコミットとファイルのハッシュは `localization/source-manifest.json` にあります。

== ローカルで確認する

英語版のフォルダをこのリポジトリと同じ親ディレクトリに置き、Node.js と Python 3 を使って以下を実行します。

[source,sh]
----
npm ci
npm run build:preview
npm run verify:preview
npm run serve:preview
----

* http://127.0.0.1:8080/ja/modules/index.html[日本語版]
* http://127.0.0.1:8081/en/modules/index.html[英語版]

英語版と日本語版は、進捗の保存領域が混ざらないよう別のポートで開きます。詳しくは link:localization/README.md[ローカル確認と OpenShift 起動後の手順] を参照してください。

== コンテンツの編集

公開する本文は `content/modules/ROOT/pages/`、ナビゲーションは `content/modules/ROOT/nav.adoc` にあります。`examples/` は執筆用テンプレートであり、公開ワークショップ本文の翻訳対象には含めていません。

OpenShift 上の反映と手動確認は、環境の起動後に実施します。ローカルプレビューだけでは、実際のサービス接続やラボの完遂は確認できません。
